# 1.6：加载优化与包名迁移

> 2026-10-11，1.6.1 更新：根据模型加载闪退反馈，已撤销下文 1.6 的模型权重进度轮询，恢复后台直接调用原生 load 和不定进度等待提示。词库加载优化、词库百分比、包名与学习记录迁移入口保留。新包名用户可直接覆盖安装 everyday-1.6.1.apk，无需再次迁移；versionCode 为 8。尚未取得真机崩溃日志，回退不等同于已确认闪退根因。

## 两个安装包

默认构建的安装包名（applicationId）为 `com.oxford.everyday`，versionCode 为 7。Android 将它视为新的应用，无法直接读取 `com.oxford.a1` 的私有数据库。

`build/deliverables/everyday-migration-old-package-1.6.apk` 使用旧包名和本机原 debug 签名，显示为「每日英语（旧版迁移）」。它可以升级已有旧应用，保留旧数据库与私有文件，并提供学习记录导出入口。`build/deliverables/everyday-1.6.apk` 是新包名应用「每日英语」。两者可以同时安装。

先安装旧包名迁移版，在「关于」中导出学习记录 JSON；再安装新包名版本，在「关于」中导入该 JSON，并核对掌握状态。不要先卸载旧应用或清除其数据；遇到签名冲突，必须用原签名重新构建迁移版。

备份仅包含已掌握词形。导入按稳定的单词 key 匹配，事务内分批设置 learned=true；重复导入安全，不将任何已掌握单词改回未掌握，不清空数据库。未知词形忽略，完成提示是匹配记录数，包含之前已标记的词。备份不包含模型、Skill、聊天或 AI 设置。模型应从原 GGUF 文件重新导入；Skill 和参数需要手动转移。确认所需内容全部转移后，再决定是否卸载旧应用。

Kotlin 源码、namespace 和 JNI 符号暂保留 `com.oxford.a1`，避免无关的类名和原生接口重命名；实际 APK 安装身份已经改为 `com.oxford.everyday`。Room 仍使用 `vocabulary.db`，数据库版本和表结构未改变。

## 启动词库加载

Gradle 在构建时读取 assets/words_*.json，生成小文件 assets/pack_index.json，其中只有文件名、数据包 ID、版本和词条数。正常启动只读取此索引和 Room 中已导入版本，不再每次解析五个完整 JSON。

仅新增或提高版本的词库才会被解析、校验和导入。导入前先校验所有待处理数据包；每包使用一个事务，预先查询已有词形映射，以 250 个词条为一批写入，替代逐词查询。更新沿用词条 ID 和掌握状态，事务失败回滚。

导入期间暂停完整词库的 Flow 查询，完成后再观察数据库，减少边导入边重复加载整个词库的开销。详情查找也避免对整库逐词构造显示信息。

界面分别显示版本检查、词库校验、导入和本地读取阶段。可计数阶段显示百分比与进度条，导入显示实际已处理条数；数据库读取等无法准确计数的阶段使用不定进度条。百分比属于当前阶段，不代表全程剩余时间。

扩展词库仍只需生成 words_*.json，并给内容变更的数据包增加 version。索引由构建自动生成，不需要手工维护；未增加 version 的数据更改不会覆盖已经导入的版本。

## 本地模型加载

llama.cpp 的 progress_callback 将权重读取进度写入原子变量。ViewModel 加载时每 100 毫秒读取一次并更新 Compose 进度条。达到 100% 后会提示「正在准备推理上下文」，因为上下文分配仍需要时间；不把权重读取完成误报为全部就绪。只有原生 load 成功返回后才进入模型已加载状态。原有停止、释放模型、TTS 和参数功能保留。

模型载入时间仍受 GGUF 大小、存储速度、内存及上下文长度影响。当前已验证编译和自动化测试，没有真机速度对比，也没有实测 3～4B 模型加载时长。

## 构建

```powershell
$env:JAVA_HOME = 'D:\Program Files\Android\Android Studio\jbr'
# 新包名，含完整验证
.\gradlew.bat :app:testDebugUnitTest :app:lintDebug :app:assembleDebug
# 旧包名迁移版；构建后需另存 APK，避免被下一次构建覆盖
.\gradlew.bat :app:assembleDebug -PmigrationBuild=true
```

APK 默认输出到 app/build/outputs/apk/debug/app-debug.apk。不传 migrationBuild 属性才是新包名版本；最后应再运行一次默认 assembleDebug，使该默认路径保持新包名。

## 主要实现位置

- data/repository/WordRepository.kt：版本索引、分阶段进度、初始化查询门控、学习记录导入导出。
- data/local/SeedImporter.kt：批量导入和保留学习状态。
- data/local/WordDao.kt：批量写入和已掌握标记合并。
- MainActivity.kt：词库加载界面和「关于」中的备份入口。
- ai/AiViewModel.kt、ai/LlamaNative.kt、src/main/cpp/native-lib.cpp：模型加载进度。
- LoadingMigrationTest.kt：批量进度、重复启动跳过 JSON、学习标记备份合并测试。
