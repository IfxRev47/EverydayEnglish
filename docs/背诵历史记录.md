# 背诵历史记录（1.9）

在「今日背诵计划」中点击「查看背诵记录」，按日期查看已背词数。日期按从新到旧排列，点击日期可查看当日全部单词、音标、中文释义，也可用原 TTS 播放发音。

只有在今日背诵中明确点击「今日已背过」才会进入该日记录。同一词同一天只记录一次，不同日期背过同一词分别记录。选入计划、跳过、听写提交或标记掌握不会自动算作背诵历史；历史与 learned 掌握状态相互独立。

历史实时保存：关闭应用或重启后保留，跨日后保留。从今日计划移除已背词也不会删除该词历史。当日计划完成数仍按当前计划与完成记录的交集显示，因此它可能小于历史中当天实际背过的词数。

升级时自动补存 1.8 仍保留在本机的 memorized 记录，使用其原 date，而非升级当天。在跨日清空今日状态之前先归档，因此旧应用留着昨日的完成记录时也能补存。1.8 已经清除的更早记录没有可用来源，不能从掌握标记推算背诵日期。

历史保存日期与稳定的 Word ID，展示时读取当前词库内容。若将来词条不在本地词库中，仍保留 ID 记录并提示缺失，不删除历史。日期依据设备本地日期；仅显示实际背过词的日期，不自动填充无学习记录的日期。

## 实现

- StudyProgressStore：在原 study-progress SharedPreferences 中新增 history_YYYY-MM-DD 去重 ID 集合。完成背诵时与当前 memorized 同一次写入；旧状态归档与跨日清空也使用同一个编辑器提交，合并不会覆盖已有历史。
- PracticeViewModel：增加历史 StateFlow，完成背诵与刷新时更新，打开记录时再次刷新。
- MemorizationHistory.kt：日期列表与逐词详情 Dialog，使用 LazyColumn；关闭或返回日期列表时停止朗读。
- TodayPlanner / PracticeScreen：增加入口并接入历史 UI。

不变更 Room 数据库结构，不改词库 JSON，不改 AI 或模型加载方式。原「导出学习记录」文件仍仅包含掌握标记，不包含计划、背诵历史或模型设置。历史保存在当前应用私有空间。

安装 `build/deliverables/everyday-1.9.apk` 覆盖现有 `com.oxford.everyday`，versionCode 11；不要先卸载，以保留本机数据。
