# 模型参数与 AI 语音（App 1.4）

首页「AI 助手」→「参数 / 语音」。模型/造句页面也有同名入口。调整后点击「保存参数」，设置保存在本机，聊天与造句共用。

## 可调参数

| 参数 | 默认值 | 范围 | 作用 |
| --- | --- | --- | --- |
| Temperature | 0.65 | 0～1.5 | 越低通常越稳定；0 使用贪心采样，此时忽略 Top-P / Top-K |
| Top-P | 0.9 | 0.1～1 | 按累计概率筛选候选词 |
| Top-K | 40 | 1～100 | 先限制候选词数量 |
| 重复惩罚 | 1.1 | 1～1.5 | 1 不惩罚；根据最近 64 个 token 降低重复倾向 |
| 最大回复长度 | 384 token | 64～768 | 限制本次生成长度，不是中文字数 |
| 上下文大小 | 2048 token | 1024 / 2048 / 4096 | 越大越占内存；保留回复预算后再计算可用提示长度 |
| CPU 线程 | 不超过 4，按 CPU 数量 | 1～8 | 更多线程不保证更快 |
| 记忆轮数 | 2 | 0 / 1 / 2 | 0 表示每次只带 Skill 和当前问题 |

这里是手机内的 llama.cpp 参数，不需要连接 Ollama 服务。数值同时在 Kotlin 与 JNI 校验。温度为正时，采样顺序为 Top-K → 重复惩罚 → Top-P → 温度 → 随机采样；温度为 0 时仍保留重复惩罚，再选概率最高的 token。

更改**上下文大小或线程数**会释放已加载模型，提示重新加载；只保存采样参数、记忆轮数或语音设置无需重载。生成期间不能进入参数页面。恢复默认值只修改表单，仍需点击保存。

输入预算取实际已加载上下文长度减去最大回复 token；超出时按完整轮次移除最早历史，保留 Skill 和本次消息。两者仍放不下时提示缩短。选择 1024 上下文并设置很长回复时，可用输入会明显减少；原来的字符上限不意味着必然能装入 token 预算。

## TTS 与 AI 如何结合

- 聊天每条已结束的回复下有「朗读英文」；造句结果下也有同样按钮。
- 「生成完成后自动朗读英文」默认关闭。开启并保存后，后续正常完成的聊天回复或造句会自动送入离线 TTS。
- 只提取英文与相关数字、标点，跳过中文、代码块和 `<think>` 思考段；这是文本规则处理，不是完整 Markdown 或语言识别器。
- 语速范围 0.5～1.5，默认 0.85；音调 0.8～1.2，默认 1.0。系统语音引擎的具体表现可能不同。
- 长文本按不超过 1000 字符（同时受 Android TTS 输入上限约束）分段，上一段结束后才播放下一段。
- 点击「停止朗读」、开始新生成、切换页面、进入后台或失去音频焦点时，停止当前发音并清空未播放片段。迟到的旧回调不会启动下一段。
- 自动朗读只在对应的 AI 页面处于前台时发生，没有重播缓存；旋转屏幕或返回页面不会补读旧消息。取消、失败的生成不触发自动朗读。达到长度上限的生成视为结束，可能朗读未完整收尾的句子。
- 手动可以朗读已停止回复中留下的英文部分。纯中文输出会提示没有可朗读的英文。
- 继续使用已安装的**离线英语语音包**，优先英式语音。缺少语音包时通过参数页进入系统 TTS 设置安装。没有新增联网语音、录音或麦克风功能。
- 单词发音仍使用原来的语速 0.85、音调 1.0；AI 的语音参数不会改变单词页发音设置。

## 实现位置

| 文件 | 职责 |
| --- | --- |
| `ai/AiSettings.kt` | 参数、边界验证、SharedPreferences 持久化及重载条件 |
| `ai/AiSettingsScreen.kt` | 参数表单、恢复默认与系统语音设置入口 |
| `ai/AiViewModel.kt` | 保存参数、模型重载状态、生成完成时发送一次性语音事件 |
| `ai/LlamaNative.kt` / `cpp/native-lib.cpp` | 传递并使用线程、上下文、采样和长度参数 |
| `audio/SpeechText.kt` | 英文内容清理、长文本分段 |
| `audio/TtsAudioProvider.kt` | 离线语音、顺序播放、语速/音调、音频焦点与停止 |
| `ai/AiSpeechControls.kt` | 手动朗读、停止、语音状态 |
| `MainActivity.kt` | 只在 RESUMED 生命周期和正确页面接收自动朗读事件 |

Kotlin 路径相对 `app/src/main/java/com/oxford/a1/`，原生路径相对 `app/src/main/`。参数保存到独立的 `ai-settings` SharedPreferences，不更改 Skill、模型文件和 Room 数据库。

版本 1.4 / versionCode 5，使用原包名与签名覆盖安装。词库、掌握状态、模型副本与自定义 Skill 保留。测试与实际设备验证边界见 [验证记录](../VALIDATION.md)。
